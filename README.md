# Magic8Ball
A beginner-friendly Python project that simulates a Magic 8 Ball using random responses.

This project is a Python implementation of the classic Magic 8 Ball, a simple program that returns a randomized response to a user’s question. The goal of the project is to practice basic Python concepts such as conditional statements, lists, randomization, and user input handling.

The program simulates the behavior of a Magic 8 Ball by selecting a response at random from a predefined set of answers, including positive, negative, and uncertain outcomes. Each run produces a different response, demonstrating the use of Python’s random module.

This project is beginner-friendly and serves as an introduction to control flow, data structures, and program logic, making it suitable for anyone starting out with Python.
